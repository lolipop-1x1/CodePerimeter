## 用户流程

用户只需选择监控目录并运行既有监控服务。全部受支持工具默认自动识别，不增加逐工具选择、压缩格式配置或专门启动压缩工具的要求。终端、脚本或其他进程调用受支持工具时，使用同一系统事件观察链路。

## 支持范围

| 工具名称 | 目标正向模式 | 需排除的反向／非压缩模式 |
| --- | --- | --- |
| tar、bsdtar、gtar | 创建、追加、更新归档，含适用的压缩选项 | 解包、列表等非创建模式 |
| zip | 创建、添加／更新归档 | 查看、完整性检查及其他不创建／更新的模式 |
| ditto | 显式创建归档 | 复制、解包 |
| gzip、pigz、bzip2、pbzip2、xz、zstd | 明确输入文件的压缩，含默认压缩模式 | 解压、测试、列表等非压缩模式 |
| 7z、7zz、rar | 添加／创建与更新归档 | 解包、列表、测试及删除等非压缩模式 |

- 共 14 个名称，其中 11 个为新增解析入口。工具支持的实际参数须依据对应版本官方文档与合成调用核实，不能仅扩大规则名称列表。
- 覆盖常见直接文件／目录参数，适用的递归、压缩级别、保留源文件和输出选项；工具本身不支持的模式不伪造支持。
- 覆盖落盘输出，以及工具支持的“明确项目输入文件到标准输出”模式。没有落盘文件不能使后者的命令迹象丢失。
- 相对路径使用可信工作目录解析；处理空格、选项终止符与输出参数时不把选项值当作输入。
- 列表文件、无法解释的选项或不完整事件明确报告覆盖缺口，不读取列表补全输入，不猜测输入、输出或工作目录。反向模式的识别不受后续路径猜测影响。
- 不因工具名字出现在进程事件中就告警：命令须有可关联的保护目录证据。纯标准输入且缺少项目证据时不能推断项目来源；本轮不增加跨进程管道数据追踪。
- 多个输入与适用的多个输出不得被误解析为一个输入／输出；不凭原有单输出模型杜撰路径。

## 告警与证据契约

- 沿用归档命令迹象、归档输出迹象与批量文件访问的独立规则。命令告警说明观察到的操作线索，不宣称成功压缩、确认文件内容、外传或拦截。
- 与保护目录无关的压缩操作不产生项目关联命令告警；解压、查看和测试不产生该命令的压缩／归档命令告警。普通文件活动及其他规则独立记录。
- 沿用即时生成、SQLite 保存、可用桌面会话通知发送及同进程同规则 60 秒合并；告警触发后的 3 秒目标按既有观察 MVP 验收口径验证。
- 原有归档后缀与输出行为关联继续提供辅助线索，不能把后缀识别冒充新增命令解析。
- 不保存完整命令行、环境变量、密码参数、文件正文或列表正文；错误与缺口信息也不能回显这些值。

## 最小验收

| 检查项 | 成功条件 |
| --- | --- |
| 默认识别 | 选定合成目录后，全部 14 个名称无需单独配置；已有 tar／bsdtar／zip 行为保留 |
| 正向操作 | 每个工具的支持形式正确提取输入与适用输出；未知参数报告缺口，不伪造路径 |
| 反向操作 | 逐工具测试适用的解压、列表、测试等模式，不产生该命令的压缩／归档命令告警 |
| 标准输出 | 每个支持该模式的工具使用明确合成项目输入，真实捕获命令迹象；不能依赖落盘后缀触发代替 |
| 标准输入缺口 | 无可关联项目证据时报告覆盖缺口，不假装知道管道中的项目内容 |
| 路径与范围 | 相对／绝对路径、空格、选项终止符、多个输入与无关目录对照符合契约 |
| 隐私 | 合成密码与正文标记不进入持久化、终端、错误、通知或提交材料 |
| 真实采集 | 准备所有工具，逐一通过真实 eslogger → 解析 → 项目规则 → SQLite／通知发送链路，不用合成事件回放替代 |
| 时效与证据 | 每工具记录实际可执行身份、版本、支持调用、真实事件／告警、延迟与覆盖缺口；符合既有 3 秒目标 |
| 既有回归 | 相关组件、CLI／持久化回归、格式与静态检查通过；新增命令的失败不掩盖为通过 |

真实执行只使用独立合成目录，不导入真实历史候选。不向外部服务上传测试项目。公开仓库及忽略目录均不保存真实个人路径或原始系统事件；必要的本机原始数据只在项目外受限位置临时处理，项目内只保留匿名摘要。

- 若工具执行、管理员采集权限或系统授权阻塞，保留失败证据并标为未完成；不以组件测试替代用户要求的全部真实验收。
- 任意未知工具、改名工具、程序内部库压缩、预先读入内存的数据和跨进程管道来源还原不属于本轮新增直接识别承诺。
