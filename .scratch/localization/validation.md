# 多语言实现与验收记录

日期：2026-10-07。

## 实现结果

- 简体中文与英文覆盖七页网页、详情、弹窗、错误、辅助功能标签、通知、CLI 帮助、人类提示及产品原生提示。
- 侧栏语言菜单保存当前用户统一偏好；默认跟随 macOS 首选语言，未支持语言回退英文。CLI `--language` 仅临时覆盖。
- 独立私有 `language.json` 保存偏好，不修改证据 SQLite 模式。认证与来源检查覆盖偏好 HTTP 接口。
- 文案、复数及命名参数集中管理，资源离线交付；登记新语言后不要求逐处修改页面业务代码。
- 日期与数字按语言显示，使用本机时区与 24 小时制；午夜显示为 `00:xx`。
- 历史代码提供当前语言解释，原文、路径、备注与机器导出保留原值。同次通知使用一致的语言快照，已送达通知保留原语言。
- 英文默认 README、中文版本及两种语言的使用／后台权限说明已完成；没有新增语言贡献功能或指南。

## 仍待真实系统复验

- 实现验收阶段未安装／替换真实后台程序；随后用户已追加授权单独提交并推送本轮多语言改动。
- 真实后台在网页关闭后切换语言、发送两种语言通知并确认到屏，尚未验收。helper 协议和模板测试不能替代到屏证据。
- 已验证页面进程重启后读取保存偏好；实际 Mac 重启后的后台、网页与通知一致性尚未复验。
- macOS 自身的权限窗口遵循系统语言，不受产品语言菜单控制。
- 其他语言的文字方向、翻译质量及排版需按实际语言另行验收。
