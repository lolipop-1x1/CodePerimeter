# 清理主干历史中的前端构建产物

## 范围

- 从 `main` 的所有历史版本中删除 `web/dist/`。
- 保留提交数量、父子关系、作者和时间、提交说明，以及其他文件内容。
- 保留 `web/public/` 源图标和文档中的产品截图。
- 清理前在项目目录之外建立访问受限的持久化备份，在隔离副本中实施和验证。
- 清理准备阶段不强推旧仓库，不修改 GitHub 仓库名称、可见性或 PR。

## 验收

- 清理后主干仍有 102 个提交，历史树中不存在 `web/dist/`。
- 逐提交验证其他文件及元信息不变，最新文件树完全一致。
- 验证 Git 对象完整性、备份可恢复以及隔离副本仅包含主干引用。
- 明确报告提交 ID 的变化和结果适用范围。

## 后续授权

用户随后确认采用独立仓库迁移方案，详见 [仓库迁移规格](../repository-migration/spec.md)。清理结果将在迁移时应用到本地主干和新仓库，旧仓库历史保留。
