# 中英文 README 与产品配图

## 目标与范围

面向首次使用的开源项目读者，优化英文默认 README 与中文版本：说明产品价值、当前观察能力、构建与首次使用、权限、目录管理、通知、规则及停止方式。

强调 CodePerimeter 的监控数据在本机处理与保存，不依赖云端分析或翻译。不把被监控工具的网络行为与本产品的数据处理混淆；不针对具体品牌暗示未经验证的窃取行为。

用内置 imagegen 生成品牌头图，用当前真实网页组件和明确合成数据生成中英文截图。截图不包含真实项目、用户名、邮箱、路径、令牌或浏览器地址栏；演示数据不作为真实采集或防护验收证据。

## 完成条件

- 两种 README 内容一致，快速开始步骤、权限目标和停止方法可核查。
- 图片保存到 `docs/images/`，所有相对链接有效。
- 截图明确使用匿名演示数据，头图为品牌插画而非能力证明。
- 区分访问线索、归档迹象、真实发送与拦截；说明延迟、持续 CPU 和重启仍有验证边界。
- 不修改业务代码，不恢复用户已停止的真实后台。
