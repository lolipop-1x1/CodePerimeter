# CodePerimeter 原生通知身份

Status: done
Type: task
Blocked by: 04

## 范围

2026-10-07 用户确认 AppleScript 告警到屏，但在通知中心归属“脚本编辑器”，要求改为正常 macOS 应用通知。采用 CodePerimeter 名称、独立 bundle 标识和图标的普通用户本地通知助手；共享规则与通知队列仍由现有 Rust 宿主维护。

## 验证

- Swift 助手、应用包与本机 ad-hoc 签名可构建，不依赖用户付费开发者账号；分发签名／公证另验。
- 状态查询不弹权限；启动通知角色时显式申请通知许可；发送未授权、被拒绝、超时或系统错误时记录失败。
- 只接受有界 stdin JSON 和固定操作，通知正文不进入进程命令行或诊断日志。
- 实际通知以 CodePerimeter 名称／图标出现在 macOS 通知中心；API 接受回执与到屏分别核对，3 秒发送标准保留。
- 不请求 FDA，不增加网络推送，不回退 AppleScript 伪成功。
