# 本机网页监控控制台

日期：2026-10-06
状态：已确认实施规格；2026-10-06 用户授权实施与端到端测试，代码已进入集成验收。

## 已确认

- 用户要求增加功能较完整的可视化操作与查询入口，优先网页，后续再考虑原生客户端。
- W1：仅在监控电脑的本机浏览器访问，不增加局域网或互联网远程入口。
- 关闭网页后，后台监控继续；记录留在本机。
- W2：三类内置规则提供说明、独立开关，以及批量阈值、统计窗口、告警合并时间、归档关联时间的全局设置，修改后持久保存。自定义条件和按目录覆盖规则暂不纳入本版。
- W3：网页发起安装／启动／停止等管理员操作，由本机程序触发 macOS 系统授权窗口；管理员密码仅由系统窗口接收。完全磁盘访问仍在系统设置确认，授权路径须单独真实验证。
- W4：“暂停监控”只暂停采集，保留控制台、管理与查询，可继续查看历史、修改目录与规则，并从网页恢复监控。
- W5：文件活动、归档迹象及告警支持实时更新与历史回查，按目录、进程、时间及类型筛选，支持完整分页、详情关联跳转和当前筛选范围的 JSON／CSV 导出。打开与映射分别标注，不展示未采集的读取字节数。
- W6：告警中心提供未读／已读、待处理／已处理及处理备注。人工处理状态与系统通知发送状态分别显示，不代表实际拦截。
- W7：目录入口提供手动路径、macOS 原生目录选择和 Codex／Claude Code／ZCode 历史候选预览、勾选导入；可临时停用单个目录，保留配置和历史。移除目录仅移除监控配置，不删除项目文件或既有历史。
- W8：规则开关与参数保存后对后续事件即时生效，无需重启；关闭告警规则仍保留文件活动。旧告警保留当时的规则版本与参数，不按新规则重算。变更时清空尚未完成的规则统计窗口，前后版本的告警不继续合并。
- W9：停用目录形成明确排除项，排除该目录的整个子树，优先于重叠的启用目录。页面展示实际范围及被排除的原因；重新启用或移除排除配置后，其他启用目录可恢复覆盖。移除前显示范围变化。
- W10：合并窗口内有新证据时，告警重新标为未读／待处理，保留原备注及处理历史；系统通知仍沿用首次即时发送、窗口内不重复弹窗的策略。
- 使用现有文件活动、批量文件访问、归档命令迹象与归档输出迹象的术语和证据边界。

## 用户提出的功能目标

- 启动和管理监控服务。
- 管理监控目录，保留手动与历史候选导入入口。
- 查看文件活动及归档／压缩迹象记录。
- 查看告警记录与告警规则。
- 希望功能全面完善；本版范围和完成标准已在本次访谈中确认。

## 实施前基线（规格确认时）

- 宿主提供本机 Unix socket 的状态、目录、事件、告警、健康、通知与统计请求；暂无 HTTP 接口。
- 三类告警规则固定；只有批量阈值和窗口暴露为启动参数，无运行时配置接口或规则持久化表。
- 告警目前没有已读、人工处理和备注状态；通知队列确认不能表示用户已读。
- 查询支持筛选和有限条数，无游标分页或通用事件订阅。
- 安装、启动、停止和卸载服务需要管理员权限；无现成特权服务管理 IPC。
- 当前服务停止会停止分析宿主；数据保留，但原有查询和配置入口随宿主停止而不可用。历史目录预览可以独立执行。
- 事件、告警、健康、通知反馈与通知队列按固定 30 天自动清理；累计统计保留到清除。现有清除入口只清累计统计，不清明细；尚无保留期设置、手动清除历史或记录文件导出接口。
- 托管数据库采用固定本机布局；已有 schema 升级不等于数据库文件位置迁移。本版不预设新增位置迁移功能。

## 页面与操作闭环

页面分组服务于现有观察能力，不新增文件正文读取、网络检查或拦截能力。

| 模块 | 本版功能 |
| --- | --- |
| 概览 | 分别展示安装、采集、数据库、通知和覆盖状态；近期活动与告警统计、目录及进程汇总，跳转到相应筛选记录 |
| 监控目录 | 手动路径与原生目录选择，三种历史来源预览／勾选导入，启用／停用／移除，重叠范围与排除原因 |
| 文件活动 | 实时与历史查询、完整分页、筛选、事件及进程详情；准确标注打开／映射等证据 |
| 归档迹象 | 默认支持的 14 个命令名称和覆盖说明，命令与输出迹象、关联文件活动及告警详情；不宣称压缩成功或已外传 |
| 告警中心 | 已读、人工处理、备注及处理历史，新增证据重新打开，通知发送状态独立显示 |
| 规则中心 | 三类规则说明、独立开关、四项全局参数、校验与持久化；即时生效、版本解释与历史保留 |
| 设置与诊断 | 服务操作、权限引导、采集／保存缺口、通知反馈；数据导出与清理、操作结果及失败原因 |

## 已确认的数据、运行与验收方案

### 数据管理

- 明细保留期可设置，默认沿用 30 天；累计统计保留到单独清除。缩短保留期前展示清理影响，确认后清理过期记录。
- 当前筛选范围可导出完整 JSON／CSV，不限于当前分页；提供完整字段与匿名分享两种模式。匿名模式替换路径等身份信息并移除自由文本备注，保持必要关联。导出经浏览器下载，不把真实记录写入项目目录。
- “清除明细”和“清除累计统计”分别操作，清除前展示影响并确认；明细的关联处理记录一并清除。目录与规则配置保留，用户项目文件和原始历史文件不受影响。清除后仍允许产生新的监控记录。
- 正常数据库位置固定，不增加位置迁移或备份恢复功能。

### 启动与运行

- 提供 `codeperimeter ui` 入口，在本机启动或复用控制台并打开默认浏览器；交付二进制内包含网页资源，运行时不要求另装 Node.js。
- 未安装或后台异常时仍能打开控制台，展示实际状态、安装／恢复入口；查询依赖可用的管理宿主，不把无法查询表示成零记录。
- 网页覆盖安装、启用、暂停、恢复和卸载，展示操作进度、取消与失败结果。管理员操作用系统授权窗口，拒绝授权不能显示成功；FDA 仅提供定位引导和实际采集检查。
- 已安装并启用时，后台继续沿用开机运行要求；关闭网页不停止监控。主动暂停状态跨重启保留，直到用户明确恢复；卸载默认保留配置与记录。
- 网页仅监听本机回环地址，普通用户权限运行；通过受限命令访问现有权威宿主，沿用唯一存储写入路径。网页不接收管理员密码，不提供任意命令执行入口。

### 验收与交付

- 本机真实链路：网页操作 → 本机授权／服务 → 真实系统采集 → SQLite → 网页记录／告警；同时验证三个历史目录来源、配置持久化、规则关闭与变更、排除范围、分页导出及告警处理。
- 用合成数据验证取消授权、缺少 FDA、输入非法、数据库故障、断流及宿主失联；错误与覆盖缺口可见，不虚构保存、恢复或通知成功。
- 前台可见页面在记录保存后目标 1 秒内更新。该目标单独计时；来源事件、接收、告警生成、通知发送和页面更新分别保留时间，不把已有约 20 秒的文件事件来源延迟算成界面及时。
- 归档命令与批量门槛触发后的告警生成／通知发送沿用 3 秒目标，并保留原有 14 名称覆盖和负例回归；通知到屏另取实际证据。
- 验证关闭浏览器后继续采集、暂停／恢复、后台 FDA、进入桌面后的通知／汇总及重启恢复和暂停保留。需要用户参与系统授权或重启的步骤保留明确入口及结果；未执行前标为待验证。
- Rust／浏览器／接口检查和真实 macOS 验收分别报告。交付源码构建入口与网页使用说明，本轮不扩展安装包、公证发行、远程访问、原生客户端、任意自定义规则、源码地图或外传拦截。

# 2026-10-07 用户补充：原生通知身份

用户确认告警实际到屏，并提供通知中心截图；现有 AppleScript 通知显示为“脚本编辑器”。改用 CodePerimeter 名称和应用图标的 macOS 原生本地通知，并在系统通知设置中独立显示。使用普通用户通知 Adapter，不增加网络推送或 FDA 权限；共享 Rust 规则、SQLite 与通知反馈契约继续使用。

授权拒绝、超时和系统发送错误必须保留失败，不能回退 AppleScript 来报告成功。原生 API 接受通知请求与实际到屏分别验收；3 秒标准不放宽。构建／应用包／签名方案先以本机证据验证，不能把 API 文档等同于无开发者账号的实际运行成功。
