# ZCode 历史目录发现与导入：最小规格

日期：2026-10-05
Status: claimed
Type: task

依据 [需求讨论](map.md) 的 Q1 A、Q2 A。本规格限定历史目录来源兼容，不报告 ZCode 专属运行时验收或压缩识别能力。实施在 `main` 进行，沿用用户已确认的主干开发约定。

## 目标与流程

用户执行历史目录预览时，同时发现 Codex、Claude Code 和 ZCode 本机历史中的项目目录候选；核对后按序号或全部可用候选导入。导入后复用既有后台监控、SQLite 保存和查询。

实现入口：

~~~sh
codeperimeter history preview --output candidates.json
codeperimeter history preview --zcode-db /absolute/path/db.sqlite --output candidates.json
codeperimeter history import --preview candidates.json --index 0
codeperimeter watch list
~~~

## 发现契约

- 默认 ZCode 数据库为 `~/.zcode/cli/db/db.sqlite`；`--zcode-db FILE` 覆盖此来源的位置，其他来源仍沿用已有参数和默认规则。
- 使用正常 SQLite 只读连接与一致性读取快照，包含连接时可见的已提交 WAL 记录；不使用忽略 WAL 的 `immutable=1` 扫描，也不对原库执行迁移、checkpoint 或数据写入。
- 检查实际 schema 后，窄查询 `session.directory` 及已确认含义的必要来源元字段。跳过聊天正文、标题、工具内容、认证信息，不扫描 `message`／`part` 等正文表。
- `path` 语义尚未证明，不能作为 `directory` 缺失时的猜测补全。`session.version` 的语义核验前，不冒充 ZCode 桌面应用版本。
- 非空、明确的目录元字段生成候选；空值、相对路径、失效路径、普通文件和不可访问目录按现有状态与缺口机制报告，不静默解释为没有项目。
- 支持基线为本机 ZCode 3.8.1 所观察的 schema；不同 schema、缺字段和读取失败报告缺口。仅凭版本字符串或合成 fixture 不宣称全版本兼容。
- 每次 ZCode 发现都明确说明会话中途目录变化未验证；不承诺完整还原历史工作目录，也不凭元信息确定远程工作区的执行位置。
- 数据库不存在、schema 不支持、被锁定或无法读取时，ZCode 来源报告相应缺口，其他可读取来源继续发现。

## 导入与证据契约

- 复用规范路径、目录状态、跨来源去重和显式选择。ZCode 与其他来源指向同一目录时只有一个候选，保留各自来源。
- 预览保存 `zcode` 来源和必要出处，不保存会话 ID、标题或正文。SQLite 行来源不伪造 JSONL 行号。
- 沿用当前预览结构；新程序继续读取现有 Codex／Claude Code v1 快照，旧程序不承诺读取含 `zcode` 来源的快照。
- 导入重新核对规范路径，只导入快照中选定且仍可用的目录。监控配置与 `zcode` 来源重启后仍可回查，新会话不自动扩大范围。
- 来源标签说明目录候选从何而来，不作为某个运行时进程属于 ZCode 的证据。

## 最小验收

| 检查项 | 成功条件 |
| --- | --- |
| 基线格式 | 使用真实 schema 形状的匿名 SQLite，能发现明确保存的会话目录并显示 ZCode 来源 |
| WAL 读取与只读 | 已提交但未 checkpoint 的合成目录可见；不会向历史库写入、迁移或主动 checkpoint |
| 隐私 | 合成标题／正文／会话 ID 中的标记不进入预览、配置、输出或错误信息 |
| 路径与去重 | 空值、相对路径、失效、文件、别名和跨来源重复均有符合现有契约的结果 |
| schema 与故障 | 缺表／字段、不可读取及读取超时显示缺口，其他来源仍可返回候选 |
| 快照与导入 | 现有 v1 快照可读，ZCode 快照来源可保存；显式选择、路径复核、幂等导入与持久化回查成立 |
| 范围稳定 | 预览或导入之后新增的会话目录不自动加入监控配置 |
| 本机预览 | 普通用户只读预览本机 ZCode 数据，匿名汇总确认目录提取与覆盖缺口；不擅自导入真实候选 |
| 既有回归 | Codex／Claude Code 历史、CLI 导入与相关持久化回归通过，格式与静态检查通过 |

组件验收和本机预览分别报告。此次不要求运行真实 ZCode 任务、采集管理员授权或重新验收压缩场景；目录发现通过不推导这些能力已验证。

## 本轮不交付

完整历史正文分析、会话中途目录变化的完整还原、专属进程／子进程身份归属、远程主机监控、ZCode 真实任务的访问／打包验收、外传或压缩拦截。
