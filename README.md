# CodePerimeter · 代码门卫

面向 AI 编程工具的源码外传监控与防护。

开发者需要让 AI 理解和修改项目，同时保留对源码披露的决定权。CodePerimeter 的核心目标是发现并拦截未经批准的整仓打包、加密项目快照和批量源码外传。

优先验证 macOS 上的真实核心闭环，覆盖桌面／IDE 客户端和 CLI。正常的本地读取、搜索、编辑、构建和打包继续可用；获准模型交互也可能累计涉及整个项目。

## 当前状态

本项目重新初始化，当前为需求、调研、架构候选和验收方案的文档基线，尚未实现或验证核心防护。旧原型的实验只作为历史依据，不计入本项目的完成进度。

文件访问、归档迹象和上行流量提供风险线索；它们不能单独证明源码已外传。产品最终需要给出可追溯的发现证据和真实控制反馈。

## 下一步的决定性工作

先证明项目访问与疑似打包的可见性，再证明未经批准的外传确实受控，同时验证正常任务与检查故障时的行为。只有观测实验通过时，结果称为活动观察或风险发现；接收端证明控制生效后，才能记为外传防护通过。

代码地图、历史导入和更多平台按这些证据推进，当前不以功能数量或组件测试数量衡量核心目标是否完成。
