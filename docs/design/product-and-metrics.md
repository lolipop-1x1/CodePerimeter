# 产品形态与指标口径

整理日期：2026-10-03。产品目标见 [CONTEXT.md](../../CONTEXT.md)。本文记录此前确认的地图、热点和历史需求；实施排在核心发现／控制实证之后。

## 日常形态与风险交互

| 入口 | 用户应看到什么 |
| --- | --- |
| 菜单栏常驻 | 当前项目、纳管客户端、实际能力与覆盖缺口，按需打开主窗口 |
| 项目概览／活动 | 访问、疑似打包、外联、决定和执行结果，带来源与时间 |
| 风险确认 | 应用、项目、接收方、触发原因、待发／已发情况及未知内容 |
| 代码地图 | 目录为区域、文件为方块，按证据视图切换并下钻片段 |
| 历史导入 | 用户选定记录、本地匹配、格式能力和缺失信息 |

风险提示提供保持阻止、查看证据和有界临时放行。临时放行明确应用、目的地、期限和共享上行额度，批准后重试或重新提交。没有真实控制反馈时只能显示待处理、失败或未知；已有数据离开时显示止损。

## 代码地图

全仓视图以目录分区和文件方块展示，点选可查看对应源码片段与证据。分别切换外发范围、文件活动、工具读取和写入热点；同一颜色不混合表示上传量与读取次数。

按项目快照、客户端、接收方、时间及可识别会话筛选。无会话标识的系统活动保留未关联，不强行归入某一任务。

## 指标与证据

| 指标 | 数据来源 | 可以说明 | 不能推导 |
| --- | --- | --- | --- |
| 文件打开事件数 | 支持且实际采集的系统事件 | 所观察进程打开该路径的活动频次 | 实际 read() 次数、读到全部内容、已外发 |
| 写入事件数 | 系统写入通知 | 所观察写入活动频次 | 精确编辑轮次、改动行数 |
| 工具读取尝试／成功数 | 可验证工具调用及结果 | 所支持记录范围的读取操作 | 全部系统读取或模型语义使用 |
| 会话可见源码范围 | 历史输入、工具结果与源码匹配 | 记录中出现的可定位片段 | 每段内容已实际发送 |
| 当前版本匹配范围 | 历史片段与当前源码 | 当前内容能对应的范围 | 当时历史源码相同 |
| 本机出口提交范围 | 有对应反馈的检查／转发 | 已知提交阶段的源码证据 | 已送达远端、保存或训练 |
| 受控出口已转发覆盖 | 实际转发证据与源码匹配 | 该出口记录到的独有源码范围 | 未纳管出口或任意密文内容 |
| 接收端实收范围 | 自建接收端校验 | 合成验收实际收到的内容 | 日常任意外部服务的内部行为 |
| 重复发送频次 | 同源码范围的多次转发证据 | 片段在几次受控请求中重复出现 | 无效工作、无效上下文或模型关注次数 |

AUTH 与 NOTIFY 事件不能直接相加为成功打开次数。工具错误需另记，搜索目录不能展开为目录内每个文件都读取。工具高频活动可能是正常复核或上下文恢复，原因需关联任务证据。

## 覆盖与去重规则

- 分母为快照内项目自有文本源码字节总量；第三方依赖、生成代码和二进制的统计排除规则可查看。
- 分子为同一快照中可定位且具备相应证据的源码字节区间并集，覆盖率等于分子除以分母。
- 排除统计不缩小安全保护范围，隐藏配置、秘密、Git 历史和归档仍执行规则。
- 同一接收方的相同片段重复发送只增加频次，换服务／账号重新计量；账号未知单独归集。
- 同路径同大小不证明内容相同。版本变化后未变片段与新增片段分别处理，不同版本的比例不直接相加。
- 多文件歧义、过短片段、缺失历史源码、采集丢失和不支持格式保留未知，不把一次匹配归到所有候选文件。
- 被阻止的待发内容不计入已外发。部分提交只计有对应源码范围证据的部分，不能按网络字节比例线性折算源码比例。
- 灰色或未记录表示缺少对应证据，不表示没有访问／外发；密文不可检查时不推算其源码比例。

## 历史与保存

至少验证一条真实格式的合成记录导入，支持清单按客户端格式与版本维护。读取用户指定记录，在本地解析消息、工具结果和可验证调用，保留来源位置。

有历史源码时对应历史版本匹配；没有时只呈现当前版本匹配并注明未知。历史导入不能恢复采集前的全部系统活动，也不能凭日志接受标志推导精确网络送达。

累计统计与必要分析结果按产品保留规则保存，原始导入文件由用户管理。重复导入、追加记录、历史与实时重叠、记录格式变化都需验证去重；明细过期后累计统计不代表仍能逐事件回放。
