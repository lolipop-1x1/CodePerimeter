# 本机网页监控控制台验收

更新日期：2026-10-07。依据 [已确认规格](../../.scratch/web-console/spec.md) 和 [接口契约](../../.scratch/web-console/api-contract.md)。本页分别记录应用组件／浏览器证据与真实 macOS 系统证据。未实际执行的项目保持待验证；既有 CLI／归档命令验收不替代网页操作链路。

## 使用与构建入口

源码构建需要 Node.js 24、Rust 1.88 或更新版本，以及 Xcode Command Line Tools 中的 Swift：

```sh
npm --prefix web ci --ignore-scripts --registry=https://registry.npmjs.org
npm --prefix web run typecheck
npm --prefix web test
npm --prefix web run build
cargo build --release --locked
./target/release/codeperimeter ui
```

`npm ci --ignore-scripts` 不运行依赖生命周期脚本，包括 Carbon 安装遥测。Rust 构建嵌入 `web/dist`，交付二进制不要求用户另装 Node.js。修改网页源文件后必须重新构建网页和 Rust；CI 在编译 Rust 前检查网页类型、组件测试、资源构建和已跟踪产物一致性。

`ui` 以普通用户运行，只监听本机回环地址，启动或复用控制台并打开默认浏览器。入口凭证由本机程序交给当前标签页，不写应用日志；凭证失效时重新运行 `ui`。关闭网页或启动终端不停止后台监控。控制台不提供局域网／互联网入口，也不允许任意 shell 命令或管理员密码输入。

安装／启用／暂停／恢复／卸载从网页发起，管理员密码仅在 macOS 系统窗口输入；授权取消和拒绝都不能显示成功。完全磁盘访问仍由用户在系统设置确认。三角色任务状态、实际采集健康、数据库保存和通知反馈独立展示；任务已加载不证明真实采集或桌面通知到屏。

## 操作语义

| 功能 | 应验行为 |
| --- | --- |
| 目录 | 手动路径、原生选择、Codex／Claude Code／ZCode 候选快照勾选导入；新会话不自动扩大范围 |
| 停用目录 | 排除该目录整个子树，优先于重叠启用项；移除排除配置前展示恢复覆盖的影响 |
| 暂停监控 | 仅停止 collector；管理宿主、历史查询、目录与规则管理保留；暂停区间是证据缺口 |
| 恢复监控 | 重新加载 collector 后协调宿主意图；授权拒绝、失败或 ACK 不一致不能报告恢复成功 |
| 规则 | 三类开关与四项参数持久化并即时应用到后续事件；清旧窗口，新旧版本不继续合并 |
| 告警 | 已读／人工处理／备注独立于系统通知；新证据重新标未读／待处理并保留处理历史 |
| 查询 | 打开、映射等证据准确区分；按目录／进程／时间／类型筛选，完整分页与详情关联 |
| 导出 | 当前筛选全部分页 JSON／CSV，经浏览器下载；匿名模式替换身份／路径并移除备注 |
| 保留与清理 | 默认 30 天；缩短预览清理影响；明细与累计分别确认清理；配置和项目文件保留 |
| 卸载 | 停止并移除本服务任务，保留数据库及配置；没有宿主时查询不可用，不能显示空历史 |

匿名导出只导出已保留的必要记录，不包含原始全系统 JSON、文件正文、环境变量或完整命令行。CSV 需要防止用户字段被表格软件解释为公式。匿名映射保留同次导出的关联，不声明跨次导出身份可比。

## 应用与浏览器端到端

应用证据链为“真实浏览器 → 生产回环 HTTP → 生产普通用户宿主 → SQLite → 网页”。此阶段允许匿名采集替身，以验证查询、规则、目录与操作工作流；替身不能证明 ES、FDA、管理员授权或实际系统任务生命周期通过。

测试只使用匿名项目及合成 Codex／Claude Code／ZCode 历史，不导入真实会话。截图、浏览器会话、下载和运行数据库存放在项目外受限位置；仓库只保存脱敏数字摘要和固定失败分类。独立 `--host-socket` 测试实例禁用真实系统服务操作，避免浏览器回归改变生产服务。

验收至少覆盖七页导航、筛选与超过一页的查询／导出、目录排除及导入快照、规则持久化与版本变化、告警处理及重新打开、保留期预览／确认、分别清理、宿主失联及非法输入。空数据库或未送达的替身事件不能作为负例成功证据。

前台可见页面在事件或告警保存后目标 1 秒内更新，单独测量保存时间与页面可见时间。系统来源到采集接收、告警生成、通知发送和页面更新分别计时；真实来源延迟单独报告，不能包装为网页及时。归档命令／批量门槛触发后的告警生成与通知发送仍沿用 3 秒目标，通知 `sent` 不代表到屏。

### 重跑浏览器应用测试

两个终端使用同一个项目外私有目录。第一处启动独立生产宿主与 HTTP；第二处运行实际 Chrome。所有采集输入、数据库和历史来源均为合成数据，不安装系统任务：

```sh
mkdir -m 700 /private/tmp/codeperimeter-browser-fixture
CODEPERIMETER_BROWSER_FIXTURE=/private/tmp/codeperimeter-browser-fixture \
  cargo test --test web_http browser_fixture -- --ignored --nocapture
```

```sh
CODEPERIMETER_BROWSER_FIXTURE=/private/tmp/codeperimeter-browser-fixture \
  npm --prefix web run test:browser
touch /private/tmp/codeperimeter-browser-fixture/stop
```

启动前确认此目录是本次新建的私有位置，已有目录不要复用为真实采样存储。测试需要本机 Chrome 与回环／Unix socket 权限；结束信号让 fixture 回收其拥有的宿主、网页进程及临时数据库。报告、截图、下载放项目外；不要复制 `browser.json` 或入口凭证到仓库。修改网页并构建后，应重启 fixture，让生产二进制嵌入最新资源。

## 真实系统验收安排

确认没有既有服务冲突后，以正常网页入口打开控制台，通过系统窗口授权安装与启用；在匿名目录产生真实文件活动和归档命令，核对系统来源、SQLite 与页面详情。再验证取消授权、暂停时查询／配置继续可用、恢复后的真实事件、关闭浏览器后继续采集，以及重开控制台后的状态一致性。

真实缺少 FDA 时保留权限失败与采集缺口，不自行修改授权数据库或系统安全设置。授权窗口由用户本人确认；未经实际授权／采集的步骤保持待验证，不回退替身来宣称真实链路完成。重启、进入桌面补发和通知到屏需要单独现场证据。完整真实 14 名称／92 场景回归仍沿用 [归档命令验收](archive-command-coverage.md)，避免新网页改动破坏既有覆盖。

清理仅针对本次确认的合成实例；生产卸载与记录清除通过网页确认影响，默认保留配置与数据库。管理员授权、原始事件或真实环境路径不进入公开报告。

## 本轮现场问题与修复

- 默认浏览器中静态资源返回 403，会出现空页面。静态资源不含用户数据，来源检查限定于数据／操作 API；Host 检查、CSP 和同源资源策略继续适用，并保留加载失败时的入口指引。
- 浏览器环境出现 Origin 端口缺失时，API 只在 `Sec-Fetch-Site: same-origin` 的浏览器证据下接受本机来源；跨站、同站、其他本机端口及未知元数据不能按同源处理，Bearer 认证仍必需。依据 [OWASP 的 Fetch Metadata 防护说明](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。已在实际默认 Chrome 确认页面与数据恢复显示，并重跑两项浏览器端到端通过。
- launchd plist 改用 `Standard` 后，文件活动仍观察到积压，不能声称调度类型已解决来源延迟。曾有遗留宿主占用本机单实例锁，优雅退出后当前管理任务已接管；将以新实例单独验证。
- 采集来源诊断显示各流最新来源时间与接收时间差，缺值为未知，负差为时钟异常，不用历史最大值替代当前状态。
- 二路采集复测中，执行来源及时到达，文件活动来源仍积压；同一进程读取／映射并在内存压缩的场景在 35 秒等待期内没有收到访问事件。该场景不能算及时发现通过。
- 新版将 `open`／`mmap` 分为独立 `read` 来源，`exec` 保持独立，其余六类事件保留在 `activity`，原九类事件覆盖不缩减。三路队列轮询、断流与启动失败清理、来源序号隔离及迟到关联已通过回归；该三路候选随后取得下述读取与命令场景的真实证据。
- 三路真实采集已核验：同进程内存压缩场景仅按可见访问证据生成“批量文件访问”告警；它不证明采集器识别了内存压缩本身。读取和命令场景达到目标后，变更来源仍积压，因此继续将 `write` 隔离为第四路；`activity` 保留其余五类，九类覆盖不缩减。四路组件与现场来源均已核对，读取／命令及时，但归档输出与写入仍存在下述延迟。
- 升级后须同时核验新宿主与采集器，再确认 `exec`／`read`／`write`／`activity` 均出现、访问证据来自 `read`。兼容旧 Combined／二路采样的验收通过不能单独证明新模式有效。归档负例的读取屏障还须等待同一进程、同一文件在变更流上晚于打开的关闭事件，避免积压被误判为无归档迹象。
- 四路模式进一步要求写入来源实际出现；负例屏障必须观察同一进程代际和文件的打开、稍后的写入及再后的关闭，三路均到达才允许判断负例。旧协议仍按对应来源验收。
- 本机替换后台二进制后，既有 FDA 项显示关闭，采集报告权限不足；用户重新开启已核实安装路径的项后，三路真实事件恢复。安装／启用成功不能替代 FDA 与真实事件核验。

- 四路真实归档 runner 在受监控的合成文件上先产生打开、写入及关闭屏障，再核对同一运行实例四路均有帧且版本一致。缺路或运行身份变化不能静默降级；所有负例固定等待 Write 屏障。启动快照暂缺 Write 和完整流但缺失／变化运行身份的反误通过回归已加入。

- 四路已在实际安装角色上观察 `exec/read/write/activity`，打开／映射确属 Read。普通用户状态核对数据库 ready、零丢行、零读取丢帧及零保存缺口；这些值不代表没有来源排队。Read+Write+Close 屏障在 20 秒内未穿越，Write 稍后到达，来源至接收约 49 秒，Close 约 12 秒，Read 约 0.28 秒。
- 单文件库内 ZIP 最小重复场景三次的生成／发送分别为 1455／1641ms、3193／3430ms、2074／2302ms。两次通过、一次超时，不能据通过样本宣称稳定达到 3 秒。进一步排查来源排队、共享背压和负载波动；不缩减九类事件，也不把丢弃换算为及时。
- 四路桥接普通用户压力基准经生产 stdout reader、有界队列、轮询、换行帧编码、Unix socket 和 `CollectorClient`；两种停止场景各 8288 帧、约 21MB，九类事件及四路数量／顺序／来源正确、零丢失。Release 忙路恢复后的排空约 91.6k／98.8k 帧每秒；完整 p99 保留主动 105ms 消费暂停，恢复后各路 p99 约 0.106–3.055ms。正常停止与排空后 EOF 均回收所有自有来源和生成器。这是组件基准，未包含真实 eslogger、宿主规则或 SQLite，不能据此宣称现场积压已解决；暂不修改生产转发算法。
- 四路现场暂停再次返回命令失败；任务实际已卸载／禁用、管理宿主与通知仍运行，宿主暂停意图未同步。CLI 原先在输出步骤前退出，原生授权适配只收到笼统失败码；已修正为失败也输出结构化步骤、保留非零 CLI 退出码，网页展示静态失败步骤。取消／拒绝仍独立处理，系统 stderr 不传回网页。禁用、卸载与卸载后状态检查已分开诊断，生命周期行为暂未改变，具体现场失败环节仍待复验。

## 通知行为与详情入口（2026-10-07）

通知按三种证据分别说明行为：大量访问项目文件、启动项目压缩／打包命令、疑似压缩文件生成／修改。正文只显示程序名、项目目录名及实际关联的短输出文件名；批量通知说明打开／映射及不同文件数，归档命令不把输入路径数写成读取文件数。候选输出单独保存在告警 JSON 的 `archive_output_paths`，旧记录缺失时显示未知，不从源文件后缀猜输出；匿名 JSON／CSV 导出继续替换新增路径。

通知元数据仅携带有界告警 ID，点击正文或“查看详情”由普通用户原生 App 启动当前 UID 的受保护 CLI。CLI 取得当前本机认证入口，打开对应详情；控制台未运行时启动入口，不复用缺少详情路由的旧版页面服务。摘要或旧通知打开告警中心，过期／清除／未保存记录显示明细不可用。点击不会自动改为已读或已处理，也不会触发管理员操作。

组件回归：192 项 Rust 测试、15 项网页测试、严格 Clippy、网页类型／构建、差异检查通过；原生助手在 Apple Silicon 与 Intel 目标编译通过。新增入口升级与匿名输出路径回归也通过。3 项真实 Chrome → 生产 HTTP → 普通用户合成宿主 → SQLite 浏览器用例通过，包含七页操作、无认证入口、指定告警详情、刷新、关闭／返回、后台首次详情请求、过期与非法 ID；测试使用匿名合成事件，没有系统 ES 采集。

实际通知点击已现场验证。控制台运行时，用户点击批量访问通知，打开携带对应告警 ID 的详情入口；随后只退出网页控制台，确认入口文件消失、通知 App 已退出，后台监控保留。用户点击另一条 ZIP 输出通知后，新的控制台进程与端口启动；实际默认浏览器显示告警中心右侧“归档输出迹象”详情及合成 ZIP 文件，认证接口核对告警 ID 和候选输出一致。点击未改变已读／已处理状态，后台仍 connected、数据库 ready、通知角色在线，零丢帧／保存缺口。两次系统点击由用户完成，网页显示另有现场与接口证据；不把系统提交回执或启动器创建单独计为跳转成功。
